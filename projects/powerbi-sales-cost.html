Sales & Cost Dashboard

Managers need a concise view of sales achievement, cost structure, and gross profit to compare branches and track sales against targets.

  • Power BI
  • Power Query
  • DAX
  • Python
  • Excel
Watch demo GitHub repository
Data
~50,000 synthetic transactions
Scope
16 branches, 2 directories
Period
Jan – Dec 2026

Objectives

  • Compare actual sales with targets for each period.
  • Measure total cost, gross profit, and gross profit margin.
  • Compare performance across branches and directories.
  • Show the composition of costs and job types.

Dataset

All data was generated in Python and contains no real organizational data, names, or figures. It includes about 50,000 transaction rows for January to December 2026, 16 branches grouped into two directories, and monthly sales targets per branch.

How I built it

  1. Data modeling: Directory is the dimension table. Sales and Plan are fact tables, connected through Branch in a one-to-many relationship.
  2. Power Query: Plan data was unpivoted from wide to long format, and month numbers were derived from Indonesian month names so the result does not depend on system language.
  3. DAX measures: Total Sales, Total Cost, GP Amount, and GP %.
  4. Visual design: KPI cards at the top, trends in the middle, and branch analysis at the bottom.

Dashboard features

  • KPI cards: Total Sales, Plan, Total Cost, GP Amount, GP %.
  • Plan vs. actual sales trend.
  • Job type proportions and cost and GP composition.
  • Branch profitability analysis.
  • Filters for directory, branch, and period.

Because the data is simulated, the patterns are not real business findings. This project shows how I design and build a dashboard. It reflects the type of work I do in my internship, without using any company data.
